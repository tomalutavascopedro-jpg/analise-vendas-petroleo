# Análise de Vendas de Petróleo por Região

Projeto de análise de dados desenvolvido com Python,
Pandas e Plotly para analisar vendas de petróleo
em diferentes regiões.

#Objetivo

Analisar os dados de vendas de petróleo e identificar
padrões, diferenças entre regiões e evolução das vendas.

# Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Jupyter Notebook

# Análises realizadas

- Vendas por região
- Vendas por mês
- Comparação entre regiões
- Visualização dos resultados

# Visualizações

Os gráficos foram desenvolvidos utilizando Plotly.
